 Web-bilibili

本项目是一个基于 Vue3 和 Vite 重构的哔哩哔哩移动端 H5 页面。主要用于练习 Vue3 组合式 API 的业务拆分、移动端屏幕适配以及视频消费场景的常见交互实现。

技术栈说明

项目主要使用了以下核心工具和库，不含多余的臃肿依赖：

核心框架：Vue 3.2+ (全量使用 script setup 语法糖进行组件开发)
构建工具：Vite (提供开发阶段的高速热更新以及生产环境的打包)
路由管理：Vue Router 4.x (处理页面跳转与未登录拦截)
状态管理：Pinia (管理 Token、用户信息以及跨组件的视频播放状态)
网络请求：Axios (封装了统一的请求模块，拦截处理 401、403 等状态码)
UI 组件：Vant 3.x (主要使用了 Toast 提示、List 触底加载等移动端组件)

重构重点与踩坑记录

1. 移动端自适应布局
开发时放弃了固定像素布局，采用 rem 动态方案。通过配置 px 转视口单位的插件，将编写代码时的 px 自动转换为相对单位，解决了项目在不同尺寸手机屏幕上的缩放和错位问题。

2. 评论区与推荐列表的触底加载
为了防止一次性渲染大量数据导致移动端浏览器卡顿，利用了 Vant 的 List 组件进行分页逻辑控制。当用户滑动到距离底部一定距离时，自动触发 Axios 请求下一页数据，平滑追加新节点。

3. 用户登录态持久化
为了解决刷新页面后 Pinia 状态丢失的问题，在用户登录成功后将 Token 和基本数据同步存入 LocalStorage。每次 App 初始化时，优先从本地存储中恢复数据。

## 项目目录结构

```text
src/
├── assets/            # 全局通用 CSS 样式与图标
├── components/        # 组件目录
│   ├── common/        # 高复用基础组件（导航栏、通用按钮等）
│   ├── article/       # 视频详情页组件（评论树、回复框等）
│   └── userComponent/ # 个人中心定制组件
├── router/            # 路由配置与全局守卫逻辑
├── views/             # 页面级组件（首页、视频页、搜索页、登录注册）
├── App.vue            # 应用根组件
└── main.js            # 项目总入口

本地运行指南

1. 克隆代码到本地
git clone git@github.com:wudaixiongjie/Web-bilibili.git
cd Web-bilibili

2. 安装项目依赖（这一步前先删除package-lock.json 文件）
npm install

3. 启动本地开发服务
npm run dev
启动后在浏览器中访问控制台输出的 localhost 地址即可进行调试。

4. 打包构建
npm run build
编译产物会生成在根目录下的 dist 文件夹中。
